快速开始 · Quick start

  1. 打开 App，阅读提醒事项权限说明。
  2. 允许 Reminders 访问并选择列表，或选择“使用示例数据”。
  3. 选择报告类型与日期范围，然后生成、检查并导出报告。

Open the App, review the Reminders permission explanation, then grant access and select lists—or choose Sample Data. Select a report type and date range, generate the report, review it, and export when ready.

常见问题 · FAQ

为什么 macOS 显示“完全访问”？

这是 Apple EventKit 的系统权限名称。RemindReport 仅读取您选择的列表，不会创建、修改、完成或删除提醒事项。

“Full Access” is Apple EventKit’s system permission label. RemindReport reads only your selected lists and does not create, edit, complete, or delete reminders.

我不想授权 Reminders，可以试用吗？

可以。在首次权限说明页选择“使用示例数据”，即可体验完整的本地报告流程。

Yes. Choose “Use Sample Data” on the first permission screen to try the local reporting flow without granting Reminders access.

如何恢复 Pro 永久版购买？

在 App 的购买页选择“恢复购买”，并使用原购买所用的 Apple ID。Pro 是一次性非消耗型购买，不是订阅。

Choose “Restore Purchases” on the purchase screen and use the Apple ID that made the original purchase. Pro is a one-time non-consumable purchase, not a subscription.

AI 功能是否必须？

不是。报告生成、编辑和导出可完全在本地完成。AI 润色是可选 Pro 功能，需要您自行配置服务商和 API 密钥，并在每次发送前确认数据范围。

No. Report generation, editing, and export work locally. AI polishing is an optional Pro feature that uses your configured provider and API key and asks you to confirm the data scope before every request.

报告存在哪里？

报告和模板保存在这台 Mac 上。只有在您选择导出位置后，App 才会写入 Markdown、CSV 或 PDF 文件。App 没有开发者账号系统或同步服务器。

Reports and templates are stored on this Mac. Markdown, CSV, or PDF files are written only after you choose an export location. The App has no developer account system or sync server.

如何重置权限或本地数据？

Reminders 权限可在“系统设置 → 隐私与安全性 → 提醒事项”中修改。本地报告、模板和 AI 密钥可在 App 设置的隐私与数据区域中删除。

Change Reminders access in System Settings → Privacy & Security → Reminders. Delete local reports, templates, and AI keys from the App’s privacy and data settings.
